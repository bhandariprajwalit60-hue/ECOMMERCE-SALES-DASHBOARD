# Ecommerce Sales Dashboard | Power BI • Python

## 📌 Project Overview
This project focuses on analyzing ecommerce sales data using **Python for data cleaning and preprocessing** and **Power BI for interactive dashboard creation**.  
The dashboard provides insights into sales performance, profitability, customer behavior, and product trends.

---

## 📂 Dataset Information
- **Source:** Kaggle  
- **Type:** Public ecommerce sales dataset (random / sample data)  
- **Purpose:** Learning and portfolio demonstration  
- **Note:** This dataset does not represent a real company and is used only for practice.

---

## 🛠 Tools & Technologies Used
- **Python:** Data cleaning, preprocessing, and transformation (Pandas, NumPy)  
- **Power BI:** Data modeling, DAX measures, interactive dashboards, and visual storytelling  

---

## 📊 Key KPIs Tracked
- Total Sales Amount  
- Total Profit  
- Total Quantity Sold  
- Average Order Value (AOV)  

---

## 📈 Dashboard Insights
- **State-wise Sales Analysis** to identify top-performing regions  
- **Category & Sub-Category Performance** based on sales and profit  
- **Month-wise Profit Trend** highlighting seasonal gains and losses  
- **Customer-wise Sales Contribution** to identify high-value customers  
- **Payment Mode Analysis** to understand customer preferences  

---

## 🔍 Key Features
- Interactive slicers (Quarter, Category, Filters)  
- Dynamic KPI cards for quick business overview  
- Drill-down enabled visuals for deeper insights  
- Clean, business-focused dashboard design  

---

## 🔄 Project Workflow
1. Collected ecommerce sales data from Kaggle  
2. Cleaned and transformed data using Python  
3. Loaded processed data into Power BI  
4. Created DAX measures and KPIs  
5. Built an interactive sales dashboard
